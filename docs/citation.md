# Citation

If you use pefftacular in your research, please cite the software.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22925639.svg)](https://doi.org/10.5281/zenodo.22925639)

The DOI [10.5281/zenodo.22925639](https://doi.org/10.5281/zenodo.22925639) covers all archived
releases on Zenodo. To cite a specific release, use the version DOI listed on that Zenodo page.

## BibTeX

```bibtex
@software{garrett_pefftacular,
  author    = {Garrett, Patrick T.},
  title     = {pefftacular: Reading and writing PSI Extended FASTA files in Python},
  doi       = {10.5281/zenodo.22925639},
  url       = {https://github.com/tacular-omics/pefftacular},
  license   = {MIT}
}
```

## CITATION.cff

The canonical citation metadata is
[`CITATION.cff`](https://github.com/tacular-omics/pefftacular/blob/main/CITATION.cff) in the
repository. GitHub's "Cite this repository" button reads the same file.
